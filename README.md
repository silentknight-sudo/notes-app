# Shivam & Swati — Roka Album

A virtual flip-book photo album of Shivam and Swati's Roka ceremony.

Open `index.html` in a browser (or enable GitHub Pages for this repo). Turn pages by clicking a page, swiping, or using the arrow keys; the magnifier button on each photo opens it full size.

Photos are loaded from the shared Google Drive folder, which must stay shared as "Anyone with the link can view". To add or change photos, edit the `PHOTOS` list at the top of `script.js` with the Drive file IDs.
